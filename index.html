Web answers for your AI assistant, over MCP

A Model Context Protocol (MCP) server that queries the DuckDuckGo Instant Answer API, so MCP clients such as Claude Desktop can look things up while they work.

What it does

One-line install

Install for Claude Desktop through Smithery with a single npx command.

Instant Answer API

Queries DuckDuckGo's Instant Answer API and returns the result to the client.

Docker ready

Build and run the server in a container on port 8080.

Inspector tested

Use the MCP Inspector to call the tool and check responses.

Get started

Manual install
git clone https://github.com/shaheen2013/duckduckgo-search-mcp-server.git
cd duckduckgo-search-mcp-server
npm install
npm run build
npm run inspector
npm run buildBuild the TypeScript code
npm run watchRebuild on changes
npm run inspectorRun the MCP Inspector
